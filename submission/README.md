# Submission Assets — technical capture pack

These are **technical/demo capture artifacts** of real app surfaces —
not a visual-final award pack. They reflect the Signal Lens redesign
(two signals → one human decision); final public-brand assets ship
with the rebrand decision (`docs/BRAND_RELEASE_DECISION.md`).

## Icon — PROVISIONAL

`voxguard-icon-1024.png` — **provisional placeholder**, generated by
`tool/generate_icons.py` at 1024×1024 and verified at exact
dimensions. Same source produced all platform densities (Android
mipmap + adaptive foreground, iOS AppIcon set, web icons/favicon).

The current shield motif predates the Signal Lens design direction
and is **not** the final brand identity. The final icon ships with
the public rebrand and must align with the SignalMark / two-signal
visual language (`docs/DESIGN_SYSTEM.md`,
`docs/BRAND_RELEASE_DECISION.md`).

## Screenshots — `screenshots/`

All frames are **1179×2556**, rendered natively at that resolution
(no upscaling, no device frame) by the deterministic capture harness:

```
flutter test test/screenshot_capture_test.dart --update-goldens \
  --dart-define=CAPTURE_SHOTS=true
```

Regenerating produces exactly these paths — no alternate numbering:

| File | Surface |
|------|---------|
| `01_home_threatcore.png` | Home — readiness hero, calm Family Shield status |
| `02_safecall_demo.png` | SafeCall demo attack — Signal Lens at high risk, evidence chips, Egyptian-Arabic transcript feed |
| `03_incident_detail.png` | Incident report — forensic detail, flagged transcript, recommended actions |

Rendering notes: fixtures obey production schemas (`highRisk`,
`full`/`partial` scope). Arabic glyphs render via Noto Naskh Arabic
(SIL OFL 1.1 — `tool/fonts/`) loaded into the test font collection as
a fallback family; on physical devices the same strings render via
the platform font stack.
