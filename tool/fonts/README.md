# Test-render fonts

`NotoNaskhArabic.ttf` — **Noto Naskh Arabic**, unmodified, used only by
the golden-file screenshot harness (`test/screenshot_capture_test.dart`)
so Egyptian-Arabic transcript text renders real glyphs under
`flutter_tester`. It is never bundled into the app.
